# 防烧屏 v3.2.9 升级说明

版本号 108 / 3.2.9。本版四件事：f4 整层透明误伤通知的修复、红果「我的」页顶部入口补遮、歌词视图父链兜底、关于页新增「兼容性名单」。未推 GitHub。

## 一、修了什么

### 1. 状态栏整层透明误伤通知图标（你上传的 4 行日志）

日志里 `zone=w1280/n1/h0/aw0/f2=19/f4=1` 反复出现：几何分区的宽度 `aw` 恒为 0，宽度判据永远失败，于是 f2 已经遮了 19 个静态节点，还要再上第 4 级「整层透明」——通知图标被一起抹掉。

修法三处：
- `aw` 改为优先取 `v.getWidth()`，`right-left` 只作兜底。
- 新增关键静态图标词表（Clock / Signal / Battery / Wifi / Network / Mobile / Carrier / Operator），三个遍历入口置位 `lastKeyHit`。
- 降级链在第 4 级前加否决：`z >= 2` 且已命中关键图标区或通知区 → 到此为止，不再上整层透明。日志标记 `/f4key`。

### 2. 红果「我的」页顶部「预约 / 游戏」入口不遮

原因：个人页判据要求「作品 + 粉丝/获赞/私密」，红果个人页没有这些词，整页放行。

修法：`isProfilePage` 加「作品 + 收藏/点赞」红果判据；新增 `hideProfileChrome`，只收屏高 21.5% 以上、高度 < 10%、宽度 < 85% 的 TextView / ImageView / ImageButton 叶子；`showAll()` 时恢复。

### 3. 歌词视图父链兜底

HyperLyric 的状态栏歌词宿主里，封面 `ImageView` 和中间的 `LinearLayout` 是系统类，包名判据够不到。`isLyricView` 加 `parentIsLyric`：向上最多找 4 层，祖先类名以歌词模块包名开头就整支保留。日志标记 `parent:hyperlyric`。

### 4. 关于页「兼容性名单」

新增二级页，列四个同机共存模块。按你的意思，**兼容 ≠ 联动**：

| 模块 | 关系 | 一句话 |
|---|---|---|
| HyperLyric · limczhh | 联动 · 开关「系统级歌词联动」 | 开：歌词视图整棵保留；关：各管各的 |
| HyperIsland · 1812z | 联动 · 开关「超级岛联动」 | 开：岛出现只遮状态栏静态图标；关：各管各的 |
| LumaCurve / HyperLux · RongShangs | 兼容 · 无交集 | 它管亮度，我们管显隐 |
| MarketingNotificationBlocker · lm060719 | 兼容 · 无交集 | 常驻 system_server 一直在拦，拦在到达 SystemUI 之前；两边常开也不互碰 |

只做说明，不做检测：不读对方配置、不按包名判定。
