# 防烧屏 v3.3.2（vc 141）：一个图标 —— 改走 miui.focus.pics

## 3.3.1 错在哪

12:16 截图：左侧有了插画，右侧（黄圈）又飘出一个同款缩略图。

原因是 `setLargeIcon` 在这台 ROM 上会被画两遍：焦点卡左侧那格吃 largeIcon，普通通知行的行尾把同一张 largeIcon 当「大图」再画一次。一张图变两个。

## 本版改法

1. **`setLargeIcon` 整个去掉**（`baseBuilder` 不再调用）。
2. **图改走 `miui.focus.pics`**：新建 `IslandNotify.pics()`，把 `Icon.createWithResource(ctx, R.drawable.notif_large)` 放进 Bundle，key 用 `miui.focus.pic_antiburn`（必须 `miui.focus.pic_` 前缀），写入 `notification.extras["miui.focus.pics"]`。
3. **`picInfo` 从 `type:1` 改成 `type:2` + `pic` 引用**：`type:1` 是「让系统去解本包的应用图标」，自适应图标解析有时成有时空（11:02 有、11:57 空，就是它）；`type:2` 是我们直接给图，不经过系统解析。
4. 只给左格（`bigIslandArea.imageTextInfoLeft` 与 `smallIslandArea`）引用这张图，**不再用 `baseInfo.picFunction`** —— 3.2.20 那次「左边空、右边飘图」是 picFunction 的用法，不是 picInfo。

这一版在图上的路径只有一条：焦点卡左格 ← pics 里那张资源图。没有 largeIcon，也就没有第二个。
