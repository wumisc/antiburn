# 防烧屏 v3.2.29 · 按 API 102 规则逐条整改 + 沙盒一查到底

## 一、对照 API 102 文档查出来的合规问题（都是真的，不是走过场）

### 1. `minApiVersion` 写错（这是硬违规）
`module.prop` 之前是 `minApiVersion=101 / targetApiVersion=102`，但我们覆写了 API 102 才有的
`onHotReloading` / `onHotReloaded`，还声明了 API 102+ 才认的 `autoHotReload`。
按文档，`minApiVersion` 是「最低要求的 API 版本」——写 101 等于告诉一个只支持 101 的框架
「你可以加载我」，而它根本没有这两个回调。已改成 `minApiVersion=102`。

### 2. `onHotReloading` 先退役、后验证，会把模块自断
原实现顺序是：退役旧代 → 保存 Application → 若拿不到 Application 就 `return false`。
问题：`onHotReloading` 返回 false 表示**取消热重载**，此时旧代已经被我们自己拆了、框架也不会换新代码，
模块直接变植物人。现在改成：先取 Application → 为空立即 `return false`（不做任何副作用）→
保存成功 → 才退役 → 返回 true。

### 3. 框架热重载与模块自换代码会「两代同时装」
管理器若既支持 `autoHotReload`、我们的 SelfReload 又在 20 秒轮询里先动手，两边各装一套 =
双浮层 / 日志翻倍 / 状态栏抽搐。现在加了跨代记账（provider 存三个时间）：
- `SelfReload` 发现本版已被框架热重载（`reloadAt >= apkTime`）→ 不重复换，只把基线跟上；
- 框架新代在 SystemUI 里发现本版已由 SelfReload 装过（`selfAt >= apkTime`）→ 放弃装钩。
两边都只认「这一版 APK 的 lastUpdateTime」，不会误判到下一版。

### 4. 文档里其余规则逐条核过
- 恰好一个 Java 入口类（`java_init.list` 只有 `LibXposedEntry`）→ 热重载前提满足；
- `onModuleLoaded` 之前不做初始化（入口类静态字段全是常量/空引用）；
- 跨代状态只传宿主 `Application`（不属于旧模块类加载器），符合文档对 `setSavedInstanceState` 的限制；
- `onHotReloaded` 自己撤 `getOldHookHandles()` 并重装（文档明确框架不重放 package 生命周期）；
- `staticScope=true` 且 scope.list 与实际作用域一致；异常默认 protective，回调内不会把异常抛给宿主。

## 二、沙盒功能性测试（39 条，全绿，不是静态 grep）

新增/补强的用例：
1. **API102 契约（JVM 沙盒）**：直接读真实 `module.prop` + `java_init.list`，断言
   `minApiVersion=102`、`targetApiVersion=102`、`autoHotReload=true`、入口恰好 1 个且能被
   `Class.forName` 真实加载（为此把 libxposed api 作为 `testImplementation`，不进 APK）。
2. **onHotReloading 行为（Robolectric）**：构造真实的 `LibXposedEntry` 与假 `HotReloadingParam`：
   - 无 Application → 必须返回 false，且不得留下半截交接状态；
   - 有 Application → 返回 true，`savedInstanceState` 必须是宿主 Application 实例。
3. **首次安装语义**：`firstInstallStale()` 只在 `STALE && !everRan` 为真；跑过一次后更新不再提示。
4. **热重载时间戳**：`decide(apk, oldProc, 0)` = STALE；`decide(apk, oldProc, apk+1s)` = FRESH。
5. **代际标记**：`reloadAt/seenAt` 从 SharedPreferences 读写往返正确。
6. **SelfReload 判定矩阵**：从未记录、同版同路径、路径变化、框架已重载、框架重载的是上一版、
   时间为 0、路径为空 —— 7 种组合逐条钉住。
