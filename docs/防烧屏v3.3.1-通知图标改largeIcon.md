# 防烧屏 v3.3.1（vc 140）：常驻通知左侧图标改走 largeIcon

## 我认账：3.3.0 的图标没真修好

11:57 那张截图里，「防烧屏 · 运行中」卡片左侧是空的，SafeWalk 那张却有插画。上一版我把结论写成「修好了」，是越过了证据：3.3.0 只把 **smallIcon** 换成了单色矢量 `ic_tile`，但 HyperOS 焦点卡片左侧那一格画的是 **largeIcon**，不是 smallIcon —— 没给 largeIcon，那一格就是空的。smallIcon 只在状态栏小图标位生效。

## 本版改了什么

1. **新增 `res/drawable-nodpi/notif_large.png`**：直接用现有的双人撑伞图标（192×192，与桌面图标同一张），不新画。
2. **`GuardService.baseBuilder` 增加 `.setLargeIcon(largeIcon(ctx))`**：`quickBuild` / `plainBuild` / 完整版三条路径共用同一个骨架，所以三条路径都会带图标。
3. **图标用资源引用，不画位图**：`Icon.createWithResource(ctx, R.drawable.notif_large)`，由系统按密度解析。3.2.17 那次是现场用 Canvas 画 192px 位图，构造失败被 catch 吞掉后退成不可见图标，真机表现「时有时无」——这条路不再走。
4. **不会出现两个图标**：`miui.focus.pics` 自 3.2.20 起已不再下发，「左侧 pics + 右侧 largeIcon」并存的组合不存在。
