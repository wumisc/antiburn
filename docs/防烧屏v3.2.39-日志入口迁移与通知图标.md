# 防烧屏 v3.2.39（vc 138）

两件端侧改动，外加云端日志按版本清理（后端已上线）。

## 一、诊断日志开关：迁到「首页 › 功能设置」

- 「诊断日志」开关从「功能」页顶层移到首页的「功能设置」二级页（注入状态 / 白名单之后），和上传授权、清日志同屏。
- 功能页不再重复这一项；通用页计数仍是状态栏 / 导航栏 / 悬浮球三项，口径不变。

## 二、常驻通知左侧图标：小图标换单色矢量

真机截图里「防烧屏 · 运行中」通知左侧图标空白，隔壁 SafeWalk 有插画。核对结论：

- SafeWalk 那条也**没有**设大图标，左侧插画是系统焦点通知按包名自己画的；我们近三版通知代码没改过。
- 问题在 smallIcon 兜底：之前自适应图标识别失败后退的是 `ic_launcher_fg`——一张满幅不透明的彩色插画 PNG。smallIcon 必须是白色剪影，系统按 alpha 通道着色，满幅彩色插画渲出来就是一块空白 / 白块。
- 改为自适应 / 解析失败一律退 `ic_tile` 单色矢量（`plainBuild` 早就验证过任何 ROM 都能画），不再拿彩色插画当状态栏小图标。
- 左侧彩色 App 图标仍交给系统焦点通知绘制，**没有**加 `largeIcon`，避免历史上「左右两个图标」的复发。
- 真机验收通过：K90 Ultra / HyperOS 4.0.0.15，3.2.39（vc138）常驻通知左侧正常显示我方双人伞插画，无空白、无双图标。

## 三、云端日志：按版本号清理（后端，本版之前已上线）

每次上传落库成功后，删掉 `module_code` 低于本次 versionCode 的旧版本记录（含历史未带版本号的行）；同版本与更新版本保留。旧设备回传旧版本号不会反向删掉更新版本的行。
