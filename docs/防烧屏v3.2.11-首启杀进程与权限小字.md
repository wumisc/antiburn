# 防烧屏 v3.2.11 升级说明

版本号 110 / 3.2.11。本版四件事：更新后首次启动自动杀四个视频 App、公益板块改 24 小时双卡、橙色旧版提醒提到首页、权限用途写进各功能。未推 GitHub。

## 一、更新后首次启动杀四个视频 App

原来按 versionName 记账，现在改成按 versionCode：**只有更新安装后的第一次启动才杀一次**，同版本反复打开不再打断你。

- 杀的范围：抖音（含渠道包）、红果（含 oversea）、快手（含极速版）、B站（含 HD / 概念版 / 国际版）。
- 只有真的杀成功才记账。su 没授权/被拒时不记账，下次启动会再试一次；你刚授权就能补上，不会出现「第一次没 root 就永远不再杀」。
- 目的：LSPosed 只在进程启动时注入，覆盖安装后旧进程里跑的还是旧 dex。杀一次，重新打开 App 就是新代码，不用为模块天天重启手机。

日志会出现一行：`KILL ver=3.2.11 更新后首次启动，已杀：…（重新打开 App 即加载新 dex）`。

## 二、公益找孩子：24 小时、两张卡

首页放两张公益卡，上卡 1/2、下卡 2/2。

- **每 24 小时各换一位**：锚点起每过一天，两张卡一起前进两位，同一天里两条不重复；数据更新后锚点重置，最新两条顶到最前。
- **联网每天最多一次**：24 小时内只读本机缓存，不再重复拉取；超过 24 小时才联网，主通道 GitHub raw → 备通道 jsDelivr → 缓存 → 内置快照（7 条）。
- 点哪张卡就进哪一条的全文，原文跳转与宝贝回家官方联系方式不变。

## 三、橙色旧版提醒提到首页

「系统界面里跑的还是旧版」从「功能设置 → 运行方式卡」搬到**首页一级**，排在防烧屏总开关之后（总闸关着是第一顺位原因，旧版是第二顺位）。装完新版点开 App 第一眼就能看到并一键重启，不必先点进二级页才发现自己白点了。不在旧版状态时整块不渲染，平时不占空间。

## 四、权限用途写在每个功能下

做到「用到哪项权限，就在那个功能下面写一行小字」，不另设汇总页：

| 功能 | 写在哪 | 写了什么 |
|---|---|---|
| 运行方式·界面适配 | 卡片底部 | root（su）只用来看系统界面是不是旧版、重启一次系统界面；界面适配不申请系统权限 |
| 无障碍遮盖 | 引擎说明下方 | 无障碍权限只用于创建遮盖窗口，只读视图尺寸与类名，不读内容、不记录输入 |
| 注入状态 | 页底 | 包可见性（QUERY_ALL_PACKAGES）只为告诉你装没装；读 LSPosed 与 /proc 要 root，两处都只读 |
| 白名单 | 模式选择下方 | 枚举应用用包可见性权限；不授权可手动粘贴包名；名单只存本机 |
| 本应用隐身 | 卡片底部 | 不需要额外权限，只切自己的桌面入口组件 |
| 通用（通知让开） | 开关下方 | 通知权限只用于常驻提示，拒绝不影响防烧屏；开机广播只用于恢复配置并提示，不等于自启动 |
| 公益找孩子 | 页底 | 联网只给这一个板块，每天最多一次，只读不上传；断网回落缓存与快照 |
