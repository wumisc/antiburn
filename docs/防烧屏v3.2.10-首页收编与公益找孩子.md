# 防烧屏 v3.2.10 升级说明

版本号 109 / 3.2.10。本版三件事：首页卡片收进二级菜单、新增「公益找孩子」板块、换新启动图标。未推 GitHub。

## 一、首页结构调整

原来首页摆着运行方式、界面适配、注入状态、白名单、本应用隐身五张卡，一屏堆不下。

现在首页只留：
- 防烧屏总开关；
- 「功能设置」一个入口；
- 底部公益找孩子卡。

五张卡原样收进「功能设置」二级页：运行方式·界面适配合并卡、注入状态、白名单、本应用隐身。控件、开关副作用、prefs 真源一律没动，只是换了一屏摆放；二级页再进三级页（如运行方式详情）返回时回到上一级，不回退到首页。

## 二、公益找孩子板块

首页底部一张卡：照片 + 姓名 + 类型 + 走失时间地点，点进二级页看完整启事、原文跳转和官方联系方式。

**轮换规则**：每 2 天换一条；启事按注册日期倒序，最新发布顶在最前。数据更新后锚点重置，新发布的第一时间顶上来。

**数据通道（三级回落，断网也有真实启事可看）**：
1. 主通道 GitHub raw：`raw.githubusercontent.com/wumisc/antiburn-missing-kids/main/kids.json`
2. 备通道 jsDelivr CDN：`cdn.jsdelivr.net/gh/wumisc/antiburn-missing-kids@main/kids.json`
3. 本机缓存 → APK 内置快照 `assets/kids.json`（当前 7 条）。

- 只读取数，不上传任何本机信息；照片按需下载、限尺寸解码（最长边 ≤640），单图超 4MB 直接放弃。
- 数据来自宝贝回家寻子网「家寻宝贝」，仅供公益传播线索；发现疑似被拐儿童请拨 110。
- 数据管线脚本：`tools/fetch_missing_kids.py`，按注册日期倒序；抓取失败或合格条目不足 3 条时不覆盖旧文件，保证接口永远有数据。

## 三、新启动图标

三张 Q 版角色插画：
- 自适应图标（Android 8+）：前景缩到 61.8% 居中，落在 66dp 安全区，圆形 / 方形蒙版都不裁人物；背景用同图模糊填满。
- 旧版密度图标：插画全幅方形。
- 快捷磁贴仍是单色矢量（QS 磁贴只接受单色），未改。
